# Project Repository

This work compares the restless multi-armed bandit formulation for various application problems.

## Files Overview

### Core Algorithm Files

- **`solving_optimal_index.py`** - Core algorithms for computing optimal index solutions
- **`synthetic.py`** - Synthetic data generation and analysis

### Application Examples

- **`circulant_dynamics.py`** - Circulant dyanmic example
- **`maternal_health.py`** - Maternal health example application
- **`mentorship.py`** - Mentorship example problem
- **`sensor_policy.py`** - Sensor Scheduling application 
- **`restart.py`** - Example with restart
- **`update.py`** - System update application
